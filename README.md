Sou estudante de **Análise e Desenvolvimento de Sistemas (ADS)** e estou em formação para atuar como **Desenvolvedor Web Full Stack**, com foco em **Java, PHP e Frontend**.

Atualmente, trabalho no desenvolvimento de projetos próprios, explorando desde a **criação de interfaces modernas e responsivas** até a **estruturação de aplicações web completas**, sempre buscando:

- Boas práticas de código e organização de projetos  
- Versionamento com Git e GitHub

- Evolução constante no backend e frontend  

Tenho interesse em oportunidades como **Desenvolvedor Júnior / Estagiário em Desenvolvimento Web**.
